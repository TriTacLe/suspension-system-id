    1 Step test, three runs

    For each run: Reset Graph, type 1 into Offset Input, Start Logging, then Apply Input. Let the trace go visibly flat for longer than feels necessary. The settled value sets your spring coefficient, and everything downstream inherits it.

      While the graph is still up. You cannot recover these later.

      WhatHow to read itYours

      No hump at all?

      Write "no overshoot". That is a real result, not a failure: it means the system is heavily damped and has real poles. Use W = 1 below and spread the frequencies wider, roughly 0.1 to 10 rad/s.

      3 Work out your test frequencies

      W will appear here

      W is roughly the frequency the suspension wants to oscillate at, and it sets every sine run below. W = 6.28 / T.

      Tick Point Rads/sec Save as

      Amplitude 1 every time. Let each run go at least ten full cycles: the first few are settling and get discarded.

      If you run short of time

      The two green runs come first. The peak near W is your best evidence of damping, and the far point at 6W is what keeps the roll-off honest. Measured only between 2W and 4W the slope reads near -60 dB per decade and the report looks like the model failed, when it did not.

      Logging is fixed at 100 ms, so anything above about 15 rad/s has too few samples per cycle to fit. If a frequency lands above 15, enter 15 and say in the report that the sampler set the ceiling.

      4 Watch this while they run

      Note roughly how big the output swing is at each frequency, and how far behind the input it lags. The swing should grow towards W and shrink after. If it looks biggest between two of your frequencies, run one extra in that gap. That peak is the strongest evidence you will get all day, and an extra log costs three minutes.

      The lag should grow steadily. About a quarter cycle behind at W, approaching half a cycle far above it.
